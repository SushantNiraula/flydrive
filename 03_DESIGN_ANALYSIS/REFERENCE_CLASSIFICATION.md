# External Design References by Category

This note records external references collected during early design research. The category names and observations below reflect the supplied notes; they are not a final architecture decision or a validation of these designs.

## Servo Based

1. [Project HIDQ](https://github.com/aswin-sreekumar/Project_HIDQ/tree/main) — noted as a promising single-servo design.
2. [Evo-Borne](https://github.com/SRA-VJTI/Evo-Borne) — noted as promising, with four different servos required.
3. [TransformerBot](https://github.com/Incomprehensible/TransformerBot/tree/main) — reference notes list a 10:1 Metal Gearmotor 37Dx65L mm 12 V with 64 CPR encoder (helical pinion), and a Pololu Dual VNH5019 Motor Driver Shield for Arduino.
4. [Transformer Robot](https://rishika2024.github.io/posts/transformer-robot/) — additional transformation-mechanism reference.

## Linear Actuator Based

1. [Concept Design and Prototype Development of a UGV-UAV Transformer](https://github.com/Tejasva108/Concept-Design-And-Prototype-Development-Of-A-UGV-UAV-Transformer) — note: linear actuator is a major size concern in this example.
2. [Mercury Transforming Drone](https://github.com/tobieapb/mercury-transforming-drone/tree/main) — external reference for a linear-actuator-based transformation concept.

## Just Drone

1. [Pegasus CAD](https://github.com/PegasusResearch/pegasus_cad) — noted as a well-documented drone design reference.
2. [F450 Drone CAD/STL](https://github.com/sinanp1x/f450-drone-cad-stl) — structured DJI F450 CAD and STL collection, described as suitable for SolidWorks assembly and Gazebo / ROS 2 simulation setup.
3. [FPV Drone CAD Design](https://github.com/Ace-Alch/CAD_FPV_Drone) — SolidWorks 2022 design reference.
4. [Robust Quadrotor Frame for Machine Learning and Control Research](https://github.com/argmax-ai/drone-hardware) — quadrotor hardware reference.
5. [Morphing-Drone-sim](https://github.com/CAU-AISL/Morphing-Drone/tree/main) — simulation reference for a 12-actuator drone: four main motors, four tilt servos, and four flare servos; uses ROS 2 Humble and Gazebo Classic.
