# FLYDRIVE Design History

This records explored directions, not a claim that a design is complete or validated.

## Linear actuator

Explored using the [Mercury Transforming Drone](https://github.com/tobieapb/mercury-transforming-drone/tree/main) and other external examples as references. The supplied notes identify actuator size as a concern. No original FLYDRIVE actuator CAD or validated build is present.

## V2 — Worm gear

The available V2 exports cover a worm-gear/gearbox study and part of the body. The supplied assembly is partial and has no arm. It is not a complete vehicle or validated mechanism.

## V3 — Servo-based

The V3 servo-based CAD/STEP archive is filed under [V3 Servo-Based](../01_PREVIOUS_DESIGNS/V3_SERVO_BASED/). It includes an assembly, parts, alternatives, and reference models. CAD occurrence counts inform the sample BOM, but the design is an unvalidated CAD snapshot.

## External design references

The collected examples are grouped by the supplied categories in [Reference Classification](REFERENCE_CLASSIFICATION.md). These are references, not selected FLYDRIVE designs.

## Current position

No new architecture is selected. Compare mechanisms against the [basic design requirements](DESIGN_REQUIREMENTS.md), review the [six-paper research index](../02_RESEARCH_PAPERS/REFERENCES.md), then set measurable targets before committing to a new prototype.
