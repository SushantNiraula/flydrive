# V3 Servo-Based Design Archive

This directory preserves the supplied V3 servo-based CAD snapshot as a previous design exploration. It is not a validated prototype, and no new FLYDRIVE architecture has been selected.

## Contents

- `step/assemblies/` — full FlyDrive assembly, hinge assembly, and pod assembly.
- `step/parts/` — available arms, hinge shafts, clevis blocks, hubs, motor plates, guards, pinions, and pod posts.
- `step/reference/` — servo, N20 motor, T-Motor, propeller, and bearing reference geometry.
- `step/alternatives/` — chassis alternative retained for comparison.

Open the [full assembly](step/assemblies/flydrive-assembly.step) in a STEP-capable CAD program. STEP does not preserve native Fusion feature history or all assembly constraints. See the [sample BOM](../../docs/bill-of-materials.md) for CAD counts and [reference-model provenance](../../docs/reference-models.md) before reuse.

Physical fit, material selection, manufacturing, operation, and flight performance have not been verified. The archive does not establish a complete purchasing list or build cost.
