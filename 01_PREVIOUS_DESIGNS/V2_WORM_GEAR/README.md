# V2 Worm-Gear Design

This folder contains the available STEP exports from the V2 worm-gear exploration.

## Available files

- `CAD/Gearbox_Mesh_Template.step` — gearbox mesh/template model.
- `CAD/Worm_gear_partial_assembly_with_no_arm.step` — partial worm-gear assembly without the arm.

**Status:** Incomplete design. These files do not represent a complete, assembled, or validated FLYDRIVE vehicle. They are shared as a record of an earlier design exploration.
